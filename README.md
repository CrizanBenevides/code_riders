Code Riders

Code Riders é um projeto desenvolvido por estudantes com o objetivo de criar uma plataforma voltada para pessoas interessadas em ciclismo, trilhas, eventos e encontros entre ciclistas.

A proposta é facilitar a descoberta de novos lugares para pedalar, divulgar eventos e aproximar pessoas que compartilham da mesma paixão por bicicletas.

---

Objetivo

O projeto busca incentivar a prática do ciclismo e facilitar a conexão entre ciclistas, oferecendo um espaço onde os usuários possam:

* 🚴 Encontrar novas trilhas;
* 📍 Descobrir lugares para pedalar;
* 📅 Conhecer eventos e passeios;
* 🤝 Encontrar outros ciclistas;
* 🌳 Explorar novos lugares de bicicleta.

---

Sobre o projeto

O Code Riders foi desenvolvido como um projeto acadêmico, utilizando tecnologias fundamentais do desenvolvimento web.

A ideia é criar uma experiência simples, intuitiva e visualmente agradável para quem deseja explorar o mundo do ciclismo.

O projeto também busca demonstrar na prática conhecimentos de HTML, CSS e JavaScript, além de conceitos de organização e desenvolvimento de interfaces web.

---

Tecnologias utilizadas

* HTML5 — Estrutura das páginas
* CSS3 — Estilização, layout e responsividade
* JavaScript — Interações e funcionalidades
* Git/GitHub — Controle de versão e armazenamento do projeto

Funcionalidades

Página inicial

Apresentação do projeto e acesso às principais funcionalidades da plataforma.

Trilhas

Design responsivo
